# 계획 7A: UI 외 남은 일 — 구현 계획 (한국어판)

> 원본: `2026-11-11-plan7a-non-ui.md`. 두 문서는 함께 갱신합니다. UI 작업은 사용자 결정(2026-11-09)으로 뒤로 미뤘습니다.

**목표:** 심사용 빌드(2026-12-24 마감)에 필요한 UI 외 작업을 끝냅니다.
- 엔진의 메모리 사용과 대용량 복사를 줄입니다.
- 시나리오 데이터와 문구를 다듬습니다.
- 에셋 기록 양식과 생성 목록을 만듭니다.
- 배포 경로를 시험합니다.

## 전체 제약
- 공동 규칙을 따릅니다. 엔진을 바꿀 때마다 자유 모드가 C#과 같아야 하고, 턴 시간은 최악 1초, 평균 0.7초 미만이어야 합니다.
- 경제 규칙과 수치는 바꾸지 않습니다. 시나리오 수치는 데이터 파일에서만 바꾸고, 각 시나리오의 모범 플레이 순이익은 목표의 1.3배 이상을 유지합니다.
- UI 화면 배치는 바꾸지 않습니다. 화면에 이미 나오는 데이터나 문구는 바꿀 수 있습니다.
- 사용자만 할 수 있는 일은 바탕 화면의 `user_checklist\user_checklist.md`(한국어)에 정리하고, 모두 체크되면 삭제합니다.

### 작업 1: 엔진 메모리와 복사 줄이기 (Codex, gpt-6-astra, 높은 강도)
- 먼저 다음을 측정합니다.
  - 미리보기에 쓰는 메모리와 시간. 지금은 첫 미리보기 뒤 약 45MB를 더 씁니다.
  - 빌드, 불러오기, 미리보기에서 큰 상태를 복사하는 곳.
  - Edge에서 0~53턴 동안 wasm 메모리의 최고치.
- 측정 결과가 뒷받침하는 것만 고칩니다. 결과는 그대로 같아야 합니다.
- 목표: 미리보기 추가 메모리를 20MB 이하로 줄이거나 없애고, 저장할 때 말고는 세계 전체를 복사하지 않습니다.
- 바꾸기 전과 후 수치를 기록합니다.

### 작업 2: 시나리오 데이터와 문구 (Claude 문구, Codex 적용)
- 계약 사건에서 약속한 보상과 납품 때 실제로 지급된 금액을 함께 보여 줍니다.
- 시나리오 2의 조용한 주에 정해진 사건을 1~2개 추가해, 3주에 한 번쯤 판단할 거리가 생기게 합니다(데이터 파일만 수정).
- 세 시나리오의 소개, 대화창, 목표 이름의 영어 문구를 다듬습니다.
- 모범 플레이 테스트는 계속 목표의 1.3배 이상이어야 합니다.

### 작업 3: 에셋 기록과 생성 목록 (Claude 작성, Codex가 양식 생성)
- 에셋 기록 파일: 에셋마다 파일, 도구, 프롬프트, 날짜, 스크린샷을 적습니다(공모전 공개 요건).
- 그림 목록(SpriteCook)과 소리 목록(ElevenLabs): 크기, 형식, 프롬프트를 적고, 사용자용 한국어판을 둡니다.
- 나중에 UI가 불러올 에셋 폴더 구조와 파일 이름을 정합니다.

### 작업 4: 배포 경로 시험 (Codex, Copilot 점검, 사용자 계정 필요)
- 사용자가 Pages를 켜고 itch 키를 등록하면 진행합니다.
  - 푸시해서 개발 페이지 배포를 확인합니다.
  - `v0.1.0-rc1` 태그로 itch 개발 채널 업로드를 확인합니다.
- itch 화면 안에서 턴 시간을 잽니다.
- 태그와 푸시는 매번 사용자에게 먼저 묻습니다.
